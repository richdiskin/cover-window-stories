Action Network opened Oklahoma State −9.5. My card: Iowa State Cyclones +8.5, Under 57.5, and a final of Oklahoma State Cowboys 30, Iowa State Cyclones 27.

Iowa State running the clock shortens the game. My 30-27 adds up to 57, a half point under the over/under 57.5.
